Funcion de costo

La funcion de costo alineada con el proyecto es:

peajes(euros) + gasolina(euros) + (tiempo(min) / 60) * tarifa_vendedor

Se usa como referencia un vendedor en carro con salario horario igual al SMIC de Francia 2026.
